[proposals/ml03/evidence](https://github.com/ShadowStudioEnterprise/manga-list/tree/codex/ml03-technical-diagrams/proposals/ml03/evidence).

Las figuras tienen texto equivalente contiguo, título y descripción SVG, y
enlace para abrir el original. Conservan el índigo del tema sobre superficies
con contraste verificado y el estado propuesto con trazos discontinuos.

El comprobador sirve únicamente la compilación local y bloquea peticiones
externas del navegador. Verifica XML SVG, títulos/descripciones, etiquetas
sin recorte, carga de imágenes, enlaces y anclas HTML, contraste de la paleta,
desbordamiento y accesibilidad automatizada en claro/oscuro.

Comandos reproducibles, sin Firebase remoto:

```sh
npm run docs:build
npm run lint:check
npm run check:spark
node --experimental-vm-modules --test tests/spark.test.js
node scripts/check-docs-portal.mjs
git diff --check
```

La CI ejecuta ahora también el comprobador del portal después de construirlo,
aprovechando Chromium y Firefox ya instalados en el flujo existente.
Las pruebas de navegador no certifican accesibilidad humana completa ni Safari
o dispositivos físicos. Spark local verifica configuración, inventario y
guardas de despliegue; no certifica el plan remoto ni consumo facturable.
